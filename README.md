# Shape Detection Game 🎮📐

An interactive mobile game built on custom Android Canvas layouts to compute touch coordinate algorithms and validate geometric path logic.

## ✨ Features
- **Custom Canvas Rendering:** Smooth real-time graphical rendering loop.
- **Touch Coordinate Tracking:** Algorithmic detection of user-drawn shapes and vector intersections.
- **Instant Validation:** Immediate feedback logic for gameplay progression.

## 🛠️ Tech Stack
- **Language:** Java
- **Graphics/UI:** Android Studio Canvas API, XML Layouts
